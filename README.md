# Tech Stack

- React.js + Typescript
- Tailwindcss
- Vite
- Zustand
- Vike
- Vitest
- @testing-library/react
- pnpm
- eslint/prettier
- Claude code

# General considerations

- I used a 90's theme to style the app using tailwindcss
- Site is mobile-first, and it's responsive
- I used vite for it's simplicity
- I used vitest for it's speed and simplicity
- I used vike to provide me with SSG so navigation is faster for end-users, and SEO tags for crawlers.
- I used zustand for it's simplicity and also because it has native middleware support for client storage (localStorage in our case)
- For hosting, I used netlify, because it was an all static site and it's interface is very familiar to me.
